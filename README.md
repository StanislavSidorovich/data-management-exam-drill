# Database Management Exam Drill

Practice questions for the **Database Management Systems / Databases Management** course (NOVA IMS, 2026/2027).

**Open it:** https://stanislavsidorovich.github.io/data-management-exam-drill/

> **Unofficial.** This is a study aid written from the course slides. These are **not** real exam questions, and the real questions are unknown. The exam format used here is indicative.

## What's inside

- **245 questions from the slides** (multiple choice and true/false) in 8 sections, each with a short explanation and its source.
- **67 Preview questions** on topics that have no slides yet, clearly marked and left out of the mock exam.
- **Mock exam**: 25 random questions spread across the Class sections, 40-minute timer, free navigation, and scoring of +0.8 per correct answer, −0.8/n per wrong answer (n = number of options), 0 for a blank, maximum 20. You get a full review with explanations at the end.
- **Section tests**: run every question of one section, with instant feedback.
- **Practice**: mix any sections you choose.
- **My mistakes**: questions you answered wrong come back until you get them right.
- **Question bank**: search and browse all questions with answers.
- SQL and tables are shown in a monospaced font with their line breaks.
- Light/dark theme and four text sizes. Works on phone, tablet and laptop.

Direct links: `#exam`, `#bank`, `#s1` … `#s11`, in the order of the table below (for example `…/data-management-exam-drill/#s5`).

## Notes

- The Class sections are written from the slides of Class 1 to Class 5.
- The Preview sections cover DML, joins, aggregations, views, stored procedures, triggers, transactions and indexes, which are in the course programme but have no slides yet. They come from general SQL knowledge and may not match how the course teaches them.
- The exam settings are at the top of the script in `index.html`, so they are easy to change when the rules are published.
- The course slides are not included in this repository.
- Your progress is stored only in your own browser.
- Found a wrong answer or unclear question? Open an issue.

To run it locally, download the repo and open `index.html` in a browser (keep `questions.js` next to it).
